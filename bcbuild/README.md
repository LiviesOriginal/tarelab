
## Version 2 design updates

The home page is intentionally a calmer splash/reading-room page. On the Radar and Already Read are separate routes:

- `/radar/` fetches `content/radar.md`
- `/already-read/` fetches `content/already-read.md`

The pages share the same visual system and can later become app screens. The palette was shifted from blue/gray to a deep plum/cranberry fall palette, and cards use a crisp border with an offset editorial hover shadow.

# OURCADE — GitHub Pages

Arcade-style landing page for GitHub Pages.

## Setup
1. Open `index.html`.
2. Replace each `https://YOUR-DOMAIN.com/...` URL with the real URL for that game.
3. Commit `index.html` and `arcade.png` to your GitHub repository.
4. Enable GitHub Pages for the repository.

The six clickable cabinets are Pac-Man, Galaga, Sweet Fighter, The Sims, Tetris, and Made 4 U.

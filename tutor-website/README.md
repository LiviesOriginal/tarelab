# Muhil Prabakar Tutoring Website

A responsive one-page tutoring site built with React, Vite, TypeScript, Tailwind CSS, Motion for React, and Lucide icons. The design pairs a white foundation with deep navy and warm gold, using Cormorant Garamond, Inter, and JetBrains Mono.

## Run locally

```bash
cd tutor-website
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Before launch

- Replace the placeholder email address and phone number in `src/App.tsx`.
- Replace the portrait photography with approved images for the tutor.
- Replace illustrative testimonial cards with genuine, permission-approved feedback or remove them.
- Verify all subjects, curricula, qualifications, availability, and professional claims.
- Connect the enquiry form to a secure form provider or backend. It currently validates locally and tells visitors that it does not send messages.
- Publish an appropriate privacy notice and safeguarding information.
- Publish the learning journal articles and link each resource card to its actual destination.
